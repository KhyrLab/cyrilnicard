Learning by building

I started with C++ to understand programming fundamentals and the main ideas behind object-oriented programming, then learned HTML, CSS, JavaScript, PHP and SQL while gradually building my own website.

From the historical project to this version

The first Game of Life implementation was part of that learning process. This version keeps the same idea but redesigns the interface so it sits directly in the page, works responsively and is easier to use on both desktop and mobile.

The website today

The site deliberately remains static: HTML, CSS and JavaScript are enough. That makes it easy to maintain and fully compatible with GitHub Pages, with no server or external dependency.
